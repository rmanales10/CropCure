# SMS Verification Setup Guide

This guide will help you set up SMS verification using Semaphore API for the CropCure Flutter app.

## Prerequisites

1. A Semaphore account (sign up at https://semaphore.co)
2. Your Semaphore API key
3. Flutter development environment

## Setup Steps

### 1. Get Your Semaphore API Key

1. Go to [Semaphore.co](https://semaphore.co) and create an account
2. Log in to your account
3. Navigate to your account settings
4. Copy your API key

### 2. Configure the API Key

1. Open `lib/config/sms_config.dart`
2. Replace `YOUR_SEMAPHORE_API_KEY` with your actual API key:

```dart
static const String semaphoreApiKey = 'your_actual_api_key_here';
```

### 3. Test the Integration

1. Run the Flutter app
2. Navigate to the registration page
3. Enter a valid Philippine phone number (e.g., 09123456789)
4. Complete the registration form
5. You should receive an OTP via SMS

## Features Implemented

### SMS Service (`lib/services/sms_service.dart`)
- Sends OTP via Semaphore API
- Validates Philippine phone numbers
- Formats phone numbers correctly
- Handles API responses and errors

### OTP Verification Screen (`lib/user/onboarding_login/auth_screen/otp_verification.dart`)
- 6-digit OTP input fields
- Auto-focus navigation between fields
- 5-minute countdown timer
- Resend functionality (max 3 attempts)
- Real-time validation

### Updated Registration Flow
- Added phone number field to registration form
- Phone number validation
- Redirects to OTP verification after form submission
- Only proceeds with account creation after successful OTP verification

### Configuration (`lib/config/sms_config.dart`)
- Centralized configuration for SMS settings
- Easy to modify OTP length, validity period, and resend limits
- Sender name set to "ABESO" as requested

## Phone Number Format

The app accepts Philippine phone numbers in these formats:
- `09123456789` (11 digits starting with 0)
- `9123456789` (10 digits starting with 9)
- `639123456789` (12 digits starting with 63)

All formats are automatically converted to the international format `639123456789` for API calls.

## Error Handling

The app includes comprehensive error handling for:
- Invalid phone numbers
- API failures
- Network errors
- Invalid OTP codes
- Maximum resend attempts exceeded

## Security Features

- OTP codes are generated by Semaphore API
- 5-minute validity period
- Maximum 3 resend attempts
- Phone number validation
- Secure API key storage (remember to add to .gitignore in production)

## Testing

To test the SMS functionality:

1. Use a real Philippine mobile number
2. Ensure you have SMS credits in your Semaphore account
3. Check that the sender name appears as "ABESO"
4. Verify the OTP message format

## Troubleshooting

### Common Issues

1. **"Failed to send OTP"**
   - Check your API key
   - Verify you have SMS credits
   - Ensure the phone number is valid

2. **"Invalid phone number"**
   - Use a Philippine mobile number
   - Format: 09XXXXXXXXX or 9XXXXXXXXX

3. **"Maximum resend attempts reached"**
   - Wait for the timer to expire
   - Restart the app to reset attempts

### API Rate Limits

- OTP endpoint: No rate limit
- Regular messages: 120 requests per minute
- Account info: 2 requests per minute

## Cost Information

- OTP messages: 2 credits per 160 character SMS
- Regular messages: 1 credit per 160 character SMS
- Priority messages: 2 credits per 160 character SMS
